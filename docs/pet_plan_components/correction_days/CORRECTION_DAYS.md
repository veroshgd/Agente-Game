`days[d]` 是第 d 天**早晨目标更新之前**的状态（前一天结束时记录）：目标是第 d−1 天的，饱足用的是更新前的记录（当天早晨

## 解释更正

1. **两个时间窗口**：第五轮“去掉计划后补偿消失”指第 30-60 天（两者都关时状态部分 +0.08，配对差 +2.91 [+2.33, +3.52]）；

2. **状态部分不是计划的纯因果效应**：它是“该小时去掉阅读项时也会读的占比”，包含此前所有选择的后果（厌倦、计划时序、身体、
   随机数流的改变），不是计划补偿的分离估计。
3. **58 % 不是唯一的因果归因**：它只是 60 天读书差的配对增量之比（去惩罚 +4.16 / 两者 +7.14）；两部分之和不是 100 %
   （58 % + 37 %），第 30-60 天还有交互 +0.96 [+0.14, +1.74]，两部分的贡献取决于另一部分是否存在。

## 6006 / rep2 / 难书：去掉计划外惩罚后阶段失败

小屋 < 20：68 → 122 小时（4.72 % → 8.47 %，上限 8 %）。两条生命从同一状态、同一种子出发。

- **第一次分叉**：共同第 1 天（tick 515），`stock_food` 计划下，现机制探索，去惩罚后读书；此前完全相同。
- **直接作用**（同一状态下只因开关不同而改变的选择）：去惩罚的生命中只有 4 次，都在第 1-9 天，均为“读书代替探索 / 吃东西”，
  小屋 30-56；没有一次代替建造或收集材料。60 天的维护总量几乎相同：建造 22 / 21，收集材料 66 / 63。
- **之后的轨迹**：生命分叉后随机数流与身体状态不同。第 11 天开始的 `learn` 计划现机制第 12 天完成，去惩罚第 13 天完成——
  计划序列从此错开一天；随后去惩罚的生命有一个 5 天的 `stock_food`（第 21-26 天），`improve_home` 计划在第 20-40 天少了
  一半小时（120 对 264）。
- **失败本身**：两段长时间低于 20（第 26-28 天 42 小时，最低 5.4；第 34-36 天 45 小时，最低 4.5），都处在**新形成的
  `see_the_world` 计划**里（42 / 45 小时中 38 / 42 小时）。早晨小屋 14.8 / 13.6 时 v6 触发没有结束该计划（`plan_log` 无 ended：
  `improve_home` 未领先切换余量）。现机制同类情况较轻（第 49-51 天 `learn` 计划中 28 小时，最低 10.5）。
- 结论：不是“读书直接挤掉了修理”，而是轨迹分叉后计划时序错位，休闲计划恰好覆盖小屋下降期，紧急触发因余量没有结束它。
  这与第三轮“小屋 12、新休闲计划挡住修理”的已知问题同类。只有这一个案例，不能推广。
