## 缺陷 1：漏计“负面评价压低阅读”

`explain_read_value()` 只有在**获选动作**带阅读价值项时才重做选择。难书角色的项为负，读书没被选上，获选动作
（探索、睡觉……）不带该项，于是从不检查——“阻止了阅读”全部记为 0。更正：每小时在同一状态下重做完整选择
（开 / 关该项），促进 = 只因该项而读，抑制 = 只因该项而没读。

## 缺陷 2：作用强度只看了获选动作

第四轮的“平均 |打分项| 为满分的 0.4-0.7 %”取自每小时**获选动作**的项；读书只占约 8 % 的小时，其余小时记 0。

读书未被选中时，与获选动作的分差中位数为 −21 至 −30 分；49-65 % 的这些小时差距在该项上限（30 分）以内。

## 撤回

1. **“该项只在约 1 % 的小时起决定作用”**：撤回。候选组为清晰 2.2 %、难书 4.2 %；漏掉的是全部抑制。
2. **“各组作用强度相近（0.4-0.7 %）/ 候选不是靠加分更大”**：撤回“相近”。按候选上的值，低学习率组难书 5.27 分、
   候选 3.38 分，决定占比 6.1 % 对 4.2 %；候选清晰角色的项（2.07）反而小于单一评价（3.02）。“候选不是靠更大的加分
   取胜”这一半仍成立（它更小），但不能再说各组强度相同。
3. 第四轮的结论（P1、C1、K1、K3 失败；不采用）不受影响。
